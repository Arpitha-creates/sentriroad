# SentriRoad — Demo Instructions

## Demo Flow (2-3 minutes)

### Step 1: Login
1. Open http://localhost:3000
2. Click any demo account (password: `demo`)
3. Or use Demo Mode from the sidebar

### Step 2: Run Demo Inspection
1. Click "Demo Mode" in sidebar
2. Click "Run Demo Inspection"
3. Watch the 7-step closed loop

### Step 3: Authority Dashboard
1. Login as authority (suresh.authority@bbmp.gov.in)
2. View metrics
3. Check critical alerts
4. Click Map tab
5. Click Priority List
6. Open work order -> download PDF
7. Click Route Optimization

### Step 4: Crew Workflow
1. Login as crew (ramesh.crew@bbmp.gov.in)
2. View assigned work orders
3. Click Submit Repair

### Step 5: Authority Review
1. Login as authority
2. Find crew-submitted work order
3. Click Approve or Reject

### Step 6: Citizen Feedback
1. Login as citizen (ravi@example.com)
2. Find verified report
3. Submit 1-5 star rating

### Step 7: Drone Operations
1. Login as authority
2. Click Drone Ops
3. View priority zones
4. Upload drone footage
